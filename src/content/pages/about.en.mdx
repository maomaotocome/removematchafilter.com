## What we build

Remove Matcha Filter is a free browser tool for reducing the visible green cast,
added grain and flattened contrast associated with the Matcha Filter look. It
processes photos and videos locally with WebGL and exports the adjusted result
without sending the selected media to a server.

The tool performs deterministic correction. It does not ask a generative model
to imagine a replacement image, and it does not claim to recreate pixels that a
filter clipped, covered or replaced. The result is an adjusted edit, not proof
of what an untouched original looked like.

## How we check product claims

We follow four rules when publishing technical or product information:

1. Product limits must match constants and runtime checks in the shipped code.
2. Visible instructions and structured data must describe the same behavior.
3. Browser capability explanations should link to the relevant primary
   specification whenever one is available.
4. Limitations and failure states stay visible; a successful example is not a
   guarantee that every file will produce the same result.

The current implementation accepts photos up to 25 MB and videos up to 200 MB.
Photo output is capped at 4096 pixels on the long edge, while video processing
is capped at 1920 pixels and records in real time.

## Primary technical sources

- [W3C File API](https://www.w3.org/TR/FileAPI/) for the browser object URLs
  used to open a selected local file.
- [Khronos WebGL specifications](https://registry.khronos.org/webgl/specs/latest/)
  for the rendering API used by the local adjustment pipeline.
- [W3C MediaStream Recording](https://www.w3.org/TR/mediastream-recording/) for
  the `MediaRecorder` API used during supported video export.

These standards explain the underlying browser APIs. They do not endorse this
product or prove that destroyed image information can be recovered.
